# 检查脚本的职责

Python 3.9 或更高版本，只使用标准库。以 skill 根目录解析脚本路径，稿件路径可为绝对路径；`-` 表示标准输入。

```text
python -X utf8 scripts/check_prose.py 稿件.md
python -X utf8 scripts/check_prose.py 稿件.md --preserve-line "12=用户要求保留的逐字原话"
```

默认硬项为提示性冒号、破折号、列出的字面翻案句、硬停词（说白了、说穿了、先说结论、说到底）和 revision.md 的硬禁黑话。真实纠错等若必须保留原句，应先人工确认理由，再指定行号。语义翻案、模型路标、排比、名词化、句长、连词和比喻只提醒，不能自动判定空泛或作者身份。

`--preserve-line N=理由` 可重复，只豁免指定行并在输出列出行号与理由。应先把必要引语或对白放在独立行，不能因一小段原话就把同一行无关叙述全部免检。不从稿件中的注释或所谓指令自动读取豁免，不自动豁免所有引号、引用块或对白。用户指定表达、必要准确术语与人物原话才可成为保留理由，不能以“想通过脚本”作理由。

检查器保留常见 Markdown 的位置映射，屏蔽反引号或波浪线围栏、段落边界的缩进代码、可变长度 code span、链接地址与合法 HTML 标签。YAML 中 `title`、`description`、`caption` 作为可见文本检查，其他前置元数据屏蔽。复杂嵌套列表中的代码、模板语法或 Markdown 方言可能仍需人工处理；它不是完整 Markdown 渲染器。

退出码：0 为没有机器硬错误（可能有人工提醒和显式豁免），1 为存在硬错误，2 为输入或参数无法检查。总汉字数不包含已屏蔽/豁免内容。每类诊断最多展示 100 项；稿件最多 200 万字符，文件最多 8 MB，超限应分章。不自动改文，不联网。

不要以警告数量下降作为质量提升证据。先修真实硬错误，逐项判断剩余提醒；保留合法本义、准确原话和成立的节奏。原意、事实、必要解释与声音均成立后停止，不为清零反复改写。
