# 当前支持的场景

| 场景 | 活人写作 | 处理与交付 |
| --- | --- | --- |
| 普通文生图 | 不加载 | prompt → generate → 新图片与独立 session，默认 16:9 / 2K |
| 一张或多张参考图生新图 | 不加载 | reference 借用指定特征形成新构图，保留原图 |
| 编辑已有图片 | 不加载 | edit 使用 session 或源图；保留未指定修改部分 |
| 只做公众号封面 | 不加载 | 复用准确标题，默认 2.35:1 / 2K，不自动写文章 |
| 已有公众号定稿配图 | 不加载 | 保留正文，规划封面与局部插图，正文图默认 16:9 / 2K |
| 主题创作公众号图文 | 加载 | 材料检查 → article.md → 改稿 → 配图 → 文字/画面校验 |
| 参考文章原创图文 | 加载 | 提取角度与材料，原创表达，按目标平台生成图片 |
| 小红书/小绿书/XHS/RedNote 图文 | 新写或实质改写时加载 | post.md、card-copy.md、outline.md 与 1–10 张卡片，默认 3:4 / 2K |
| 微信贴图号图文 | 新写或实质改写时加载 | 以卡片可读性组织短文与逐卡文字，默认 3:4 / 2K，不强制长文 |
| 已有小红书/贴图号文案做卡片 | 原文跳过，新增概括按需加载 | 复制定稿或保真精简，图片依赖复用视觉锚点 |
| 普通文章/博客创作并配图 | 加载 | article.md 与基于前后文的独立插图 |
| 已有普通文章只加图 | 不加载 | 不擅自重写，交付新的带图版本 |
| 去 AI 味、实质改稿并配图 | 加载 | 保护声音、保留解释、删重复，再规划或更新相关图片 |
| 跨平台改编，如公众号改小红书 | 加载 | 目标平台决定篇幅与形式，重新组织文案后生成卡片 |
| 虚构故事图文 | 加载虚构规则 | 允许授权创作，检查角色与因果，不伪装成用户亲历 |
| 修改某张卡片的错字/画面 | 指定替换跳过；大幅重写按需加载 | 同步受影响定稿与 prompt，通过 asset_id 复用独立 session |
| 多资产系列与后续编辑 | 取决于是否写文案 | manifest 维护映射，按依赖顺序串行，同一资产独立会话 |
| 本地保存失败恢复 | 不加载 | recover --journal 补完本地保存，不重复生图调用 |
| 只要文字、不需要图片 | 不进入生图流程 | 不调用生图 API、不创建图片资产；作为独立写作请求处理 |

平台规则不固定选择图片模型。新任务由用户指定、环境配置、内置默认依次决定；编辑优先继承 session 模型，支持 gpt-image-2 与 nana-banana-2。不静默切换模型。

仅生成本地内容与图片，不登录、不上传、不创建平台草稿、不发布。模块调用属于 skill 工作流指令，Python 生图 CLI 仍只处理用户已整理好的 prompt，不会自动执行文章写作或联网研究。
